접선의 방정식: шесть типов задач

Все задачи 316–351 решаются одной формулой касательной. Меняется только то, что дано в условии: точка касания, наклон, точка вне кривой или вторая кривая. Для каждого типа здесь есть рецепт, разобранная ключевая задача (대표 유제) и подсказки к остальным. После каждого типа идут задачи из 문제집.

1 · 복습

Одна формула на всю главу

Аналогия

Машина ночью едет по извилистой дороге. Фары всегда светят прямо вперёд, туда, куда машина едет в этот момент. Луч фар — это касательная. Чтобы нарисовать луч, нужно знать две вещи: где стоит машина (точка касания) и куда она повёрнута (наклон).

Учебник

곡선 y = f(x) 위의 점 (a, f(a))에서의 접선의 방정식은
y − f(a) = f′(a)(x − a)

Уравнение касательной к кривой y = f(x) в точке (a, f(a)): y − f(a) = f′(a)(x − a).

В каждой задаче не хватает одной из двух деталей. Тип задачи показывает, какой именно и как её найти.

Первый вопрос к любой задаче

Точка из условия лежит на кривой? Подставь её в y = f(x). Если да, это тип 37 или 38. Если нет, точку касания нужно искать: тип 41.

Тип 37

접선의 방정식(1) 접점의 좌표가 주어진 경우

Дана точка касания. Задачи 316–322.

Учебник

곡선 y = f(x) 위의 점 (a, f(a))에서의 접선의 방정식은 다음과 같은 순서로 구한다.
(i) 접선의 기울기 f′(a)를 구한다.
(ii) f′(a)의 값을 y − f(a) = f′(a)(x − a)에 대입하여 접선의 방정식을 구한다.

Уравнение касательной в точке (a, f(a)) находят так: (i) находят наклон f′(a); (ii) подставляют его в y − f(a) = f′(a)(x − a).

Рецепт
  1. Проверь, что точка на кривой: f(a) равно данному y.
  2. Найди f′(x), потом число f′(a).
  3. Запиши y = f′(a)(x − a) + f(a) и раскрой скобки.
  4. Ответь именно на вопрос: y절편 — свободный член, x절편 — реши y = 0, площадь — нарисуй картинку.
Где ошибаются
  • Подставляют x = a в саму функцию вместо производной. Наклон — это всегда f′(a).
  • Если в точке есть буква (320: P(a, 7)), сначала найди её из f(a) = 7.
  • Для произведения g = u·v производная g′ = u′v + uv′ (322).

Ключевая задача учебника

316하 · лёгкая대표 유제

곡선 y = x³ + 2x² + x − 2 위의 점 (1, 2)에서 그은 접선의 방정식은?

Перевод: найдите уравнение касательной к кривой y = x³ + 2x² + x − 2 в точке (1, 2).

① y = 8x − 6② y = 6x − 3③ y = 6x − 4④ y = 8x + 6⑤ y = 6x − 5
Разбор
Шаг 1. точка на кривой? 1 + 2 + 1 − 2 = 2 ✓ Шаг 2. y′ = 3x² + 4x + 1, f′(1) = 3 + 4 + 1 = 8 Шаг 3. y − 2 = 8(x − 1) ⇒ y = 8x − 6

Ответ: ① y = 8x − 6

Тип 38

접선과 수직인 직선의 방정식

Прямая, перпендикулярная касательной. Задачи 323–325.

Учебник

곡선 y = f(x) 위의 점 (a, f(a))를 지나고 이 점에서의 접선과 수직인 직선의 방정식은
y − f(a) = −1f′(a)(x − a) (단, f′(a) ≠ 0)

참고: 두 직선이 서로 수직이다 ⇔ 두 직선의 기울기의 곱이 −1이다.

Прямая через точку (a, f(a)), перпендикулярная касательной в этой точке, имеет наклон −1/f′(a). Две прямые перпендикулярны ⇔ произведение их наклонов равно −1.

Рецепт
  1. Найди f′(a), как в типе 37.
  2. Переверни и смени знак: наклон −1/f′(a). Пример: 2 → −½, −½ → 2, 1 → −1.
  3. Прямая проходит через ту же точку (a, f(a)).
Где ошибаются
  • Меняют только знак (2 → −2) или только переворачивают (2 → ½). Нужно и то, и другое.
  • Ответ в виде ax + by + 6 = 0 (323): сначала получи свою прямую, потом домножь так, чтобы свободный член стал ровно +6.

Перевод: прямая через точку (1, 5) кривой, перпендикулярная касательной в этой точке, имеет уравнение ax + by + 6 = 0. Найдите ab.

① −2② −1③ 1④ 2⑤ 3
Разбор

Ответ: ③ ab = 1

Учебник

  1. Одинаковый наклон: f′(t) = m.
  2. Общая точка: f(t) = mt + n.
  3. Если известен наклон, из первого уравнения находим t, из второго — букву.
  4. Если кривая — парабола, можно короче: уравнение f(x) = mx + n имеет двойной корень, то есть D = 0.
Где ошибаются
  • Пишут только одно условие. Касание — это всегда два уравнения.
  • Забывают про условие выбора: 양수 k (334), 제3사분면 ⇒ t < 0 (336).

Тип 41

접선의 방정식(3) 곡선 밖의 한 점이 주어진 경우

Касательная из точки вне кривой. Задачи 338–345.

Аналогия

Ты стоишь в стороне от трассы и светишь фонарём так, чтобы луч лёг на дорогу точно вдоль её направления. Где луч коснётся дороги, заранее неизвестно, это и нужно найти. Обычно таких мест несколько: можно светить на ближний поворот или на дальний.

Учебник

곡선 y = f(x) 위에 있지 않은 한 점 (x₁, y₁)에서 곡선에 그은 접선의 방정식은 다음과 같은 순서로 구한다.
(i) 접점의 좌표를 (t, f(t))로 놓는다.
(ii) 접선의 기울기 f′(t)를 구한다.
(iii) 접선의 방정식을 y − f(t) = f′(t)(x − t)로 놓고 x = x₁, y = y₁을 대입하여 t의 값을 구한다.
(iv) t의 값을 y − f(t) = f′(t)(x − t)에 대입하여 접선의 방정식을 구한다.

주의: 접선의 방정식을 구할 때는 주어진 점의 좌표를 곡선의 방정식에 대입하여 그 점이 곡선 위의 점인지 아닌지를 확인한다.

Касательная из точки (x₁, y₁), не лежащей на кривой: (i) точка касания (t, f(t)); (ii) наклон f′(t); (iii) в уравнение касательной подставляем x = x₁, y = y₁ и находим t; (iv) подставляем t обратно. Внимание: сначала проверь, лежит ли данная точка на кривой.

Рецепт
  1. Подставь данную точку в кривую. Не подходит ⇒ это тип 41.
  2. Запиши касательную в общей точке t: y = f′(t)(x − t) + f(t).
  3. Подставь x = x₁, y = y₁. Получится уравнение только на t.
  4. Найди все t и для каждого запиши касательную.

Короткий путь, если точка на оси y, то есть (0, k): y절편 касательной в точке t равен f(t) − t·f′(t). Сразу пиши f(t) − t·f′(t) = k. Так решаются 339, 340, 343, 371.

Где ошибаются
  • Считают данную точку точкой касания и берут наклон f′(x₁). Это главная ошибка всего типа.
  • Теряют один из двух t (338: t = 0 и t = 2).
  • 343: касательная проходит через (0, 2), значит её y절편 — сразу 2. Считать почти ничего не нужно.

Тип 42

공통인 접선

Общая касательная двух кривых. Задачи 346–351.

Учебник

두 곡선 y = f(x), y = g(x)가 공통인 접선을 가지면 다음을 이용하여 접선의 방정식을 구한다.
(1) 두 곡선이 x = a인 점에서 공통인 접선을 갖는 경우
① x = a인 점에서 두 곡선이 만난다. ⇔ f(a) = g(a)
② x = a인 점에서 두 곡선의 접선의 기울기가 같다. ⇔ f′(a) = g′(a)
(2) 두 곡선 위의 서로 다른 점에서의 접선이 공통인 접선인 경우: 각 곡선 위의 점 (α, f(α)), (β, g(β))에서의 접선의 방정식을 각각 구하고, 두 접선의 방정식이 같음을 이용하여 연립방정식을 세워 α, β의 값을 구한다.

(1) Общая касательная в точке x = a: кривые встречаются (f(a) = g(a)) и имеют одинаковый наклон (f′(a) = g′(a)). (2) Касания в разных точках: пишем касательную к каждой кривой в своей точке (α и β) и приравниваем наклоны и y절편ы.

Рецепт
  1. Одна общая точка (347, 348, 349, 351): два уравнения f(a) = g(a) и f′(a) = g′(a).
  2. Касательная одной кривой касается другой (346, 350): сначала тип 37 для первой кривой, потом тип 40 для второй.
  3. Если вторая кривая — парабола, касание проверяй через D = 0 (350).
Где ошибаются
  • Пишут только f′(a) = g′(a) и забывают, что кривые должны ещё и встретиться.
  • В 349 точка неизвестна: из двух уравнений сначала исключи a, получится уравнение на x.

Пять главных ошибок
  • Не проверить, лежит ли точка на кривой.
  • Взять наклон из f(a), а не из f′(a).
  • Найти t и забыть ответить на сам вопрос (y절편, x절편, 넓이).
  • Потерять второй корень или не применить условие выбора (양수, 사분면, 유리수).
  • Неверно прочитать наклон прямой ax + by + c = 0: он равен −a/b.
Полезный приём

Уравнение «кривая = касательная» всегда содержит множитель (x − t)², где t — точка касания. Это ускоряет 356, 357, 359 и объясняет, почему для параболы касание — это D = 0.
