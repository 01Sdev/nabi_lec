Разминка: что мы уже знаем

f′(x) > 0

Касательная смотрит вверх, функция 증가 ↗.

f′(x) < 0

Касательная смотрит вниз, функция 감소 ↘.

знак + → −

Подъём сменился спуском: 극대 (вершина).

знак − → +

Спуск сменился подъёмом: 극소 (яма).

Важно с прошлого урока: f′(a) = 0 ещё не значит 극값. Нужна смена знака. У y = x³ в нуле f′ = 0, но знак не меняется, и вершины нет.

2 · 함수의 그래프

Как нарисовать график за 5 шагов

Представь

Ты описываешь другу маршрут в горах. Ты не перечисляешь высоту каждого метра. Ты говоришь: «Сначала подъём до вершины 1 км, потом спуск в долину −3, потом опять долгий подъём». Этого хватает, чтобы представить всю дорогу.

С графиком так же: нужны только повороты (극대, 극소), направление между ними (↗ или ↘) и пара точек на осях. Всё это даёт производная.

Учебник · 함수의 그래프

미분가능한 함수 y = f(x)의 그래프의 개형은 다음과 같은 순서로 그리면 편리하다.

(i) 도함수 f′(x)를 구한다.
(ii) f′(x) = 0을 만족시키는 x의 값을 구한다.
(iii) (ii)에서 구한 x의 값의 좌우에서 f′(x)의 부호를 조사하여 함수 f(x)의 증가와 감소를 표로 나타내고, f(x)의 극값을 구한다.
(iv) 함수 y = f(x)의 그래프와 좌표축과의 교점을 구한다.
(v) (iii), (iv)를 이용하여 함수 y = f(x)의 그래프의 개형을 그린다.

Общий вид графика дифференцируемой функции удобно рисовать в таком порядке:

  1. Найти производную f′(x).
  2. Найти x, при которых f′(x) = 0.
  3. Слева и справа от этих x определить знак f′(x), записать возрастание/убывание в таблицу (증감표) и найти экстремумы.
  4. Найти точки пересечения графика с осями координат.
  5. По шагам 3 и 4 нарисовать общий вид графика.
Пример · 예시

함수 f(x) = x³ − 3x − 1의 그래프의 개형을 그려 보자.

Нарисуем эскиз графика f(x) = x³ − 3x − 1.

Три формы кубической функции · 참고

Учебник · 참고

최고차항의 계수가 양수인 삼차함수 f(x)에 대하여 도함수 f′(x)의 그래프의 개형에 따른 f(x)의 그래프는 다음과 같다.

① 이차방정식 f′(x)=0이 서로 다른 두 실근 α, β를 갖는 경우
② 이차방정식 f′(x)=0이 중근 α를 갖는 경우
③ 이차방정식 f′(x)=0이 서로 다른 두 허근을 갖는 경우

Для кубической функции с положительным старшим коэффициентом вид графика зависит от того, сколько корней у квадратного уравнения f′(x) = 0: ① два различных действительных корня, ② один двойной корень, ③ два мнимых корня (действительных нет).

Главный вывод для задач

Кубическая функция имеет экстремум (극값을 갖는다) ⇔ у f′(x) = 0 два различных действительных корня ⇔ D > 0.

Не имеет экстремума (극값을 갖지 않는다) ⇔ D ≤ 0. Не забудь знак «равно»: случай ② тоже без экстремума.

Так решаются задачи 302, 303 и 444 из сборника. Попробуй в лаборатории ниже.

3 · 함수의 최댓값과 최솟값

Наибольшее и наименьшее значение на отрезке

Представь

Ты идёшь по горной тропе от точки a до точки b. Где была самая высокая точка за день? Может, на вершине по пути. А может, твой финиш b вообще выше всех вершин, если в конце был долгий подъём.

Поэтому кандидатов всегда два вида: вершины и ямы внутри и старт и финиш. Сравниваешь высоты всех кандидатов, и всё.

Учебник · 함수의 최댓값과 최솟값

함수 f(x)가 닫힌구간 [a, b]에서 연속일 때, 주어진 구간에서의
극댓값, 극솟값, f(a), f(b)
중에서 가장 큰 값이 최댓값이고 가장 작은 값이 최솟값이다.

Если f(x) непрерывна на отрезке [a, b], то среди значений максимумов, минимумов (внутри отрезка), f(a) и f(b) самое большое — наибольшее значение (최댓값), самое маленькое — наименьшее (최솟값).

Внимание · 주의

함수의 극값이 반드시 최댓값과 최솟값이 되는 것은 아니다.

Экстремум не обязательно является наибольшим или наименьшим значением. 극대 — это вершина только «по соседству». На всём отрезке может найтись точка выше (часто это конец отрезка).

Учебник · 참고

연속함수 f(x)가 닫힌구간 [a, b]에서 오직 하나의 극값을 가질 때, ① 오직 하나의 극값이 극댓값이면 (극댓값) = (최댓값)이다. ② 오직 하나의 극값이 극솟값이면 (극솟값) = (최솟값)이다.

Если на отрезке только один экстремум, то: если это максимум, он и есть наибольшее значение; если минимум — наименьшее. Логика: до единственной вершины функция только росла, после — только падала, выше подняться негде.

Пример

Найдём 최댓값 и 최솟값 функции f(x) = x³ − 3x − 1 на 닫힌구간 [−2, 3].

Шаг 1. f′(x) = 3(x + 1)(x − 1) = 0 → x = −1, 1. Обе точки внутри [−2, 3] ✓ Шаг 2. кандидаты: f(−2) = −8 + 6 − 1 = −3, f(−1) = 1, f(1) = −3, f(3) = 27 − 9 − 1 = 17 Шаг 3. 최댓값 = 17 (на конце x = 3), 최솟값 = −3 (при x = −2 и x = 1)

Заметь: 극댓값 1 здесь не наибольшее значение. Это и есть 주의 из учебника.

4 · 풀이 순서

Рецепт решения

Тип A · 극값을 갖는 조건
  1. Найди f′(x), для кубической это квадратный трёхчлен.
  2. «극값을 갖는다» → D > 0.
  3. «극값을 갖지 않는다» → D ≤ 0.
  4. Реши неравенство для параметра. Проверь, что спрашивают: 자연수, 정수, 최솟값…
Тип B · 닫힌구간에서 최대·최소
  1. Найди корни f′(x) = 0.
  2. Оставь только корни внутри [a, b]!
  3. Посчитай f в этих корнях и в концах a, b.
  4. Самое большое = 최댓값, самое маленькое = 최솟값.
Чаще всего ошибаются
  • Забывают посчитать значения на концах f(a), f(b).
  • Берут корень f′ = 0, который лежит вне отрезка.
  • Пишут D < 0 вместо D ≤ 0 в задачах «극값을 갖지 않도록».
  • Путают 극댓값 (локальная вершина) и 최댓값 (самая высокая точка на всём отрезке).

Задачи из учебника

301중하

사차함수 y = f(x)의 도함수 y = f′(x)의 그래프가 그림과 같을 때, 함수 y = f(x)의 그래프가 될 수 있는 것은?

Перевод: дан график производной y = f′(x) функции 4-й степени. Какой из графиков может быть графиком y = f(x)?

Варианты нарисованы по форме, как в учебнике, но не в точности.

Подсказка

Читай по графику f′ только знак: где он выше оси, где ниже. В точке a график касается оси. Меняется ли там знак? Что происходит в точке b, где f′ самая большая?

Решение
Шаг 1. x < c (кроме x = a): f′ > 0 → f возрастает Шаг 2. x = a: f′ = 0, но знак + → + не меняется → 극값 нет, только горизонтальная «площадка» Шаг 3. x = c: знак + → − → 극대 в c; после c функция убывает Шаг 4. x = b: f′ наибольшая → здесь график f растёт круче всего

Нужен график: площадка в a, подъём, вершина в c, потом спуск. ① и ② имеют вершину в b, ③ — вершину в b, ⑤ — яму в a. Подходит только ④.

Ответ: ④

302중하

함수 f(x) = x³ + 3ax² + (6a + 9)x − 7이 극값을 갖도록 하는 자연수 a의 최솟값은?

Перевод: найдите наименьшее натуральное a, при котором функция имеет экстремум.

① 2② 3③ 4④ 5⑤ 6
Подсказка

Кубическая функция имеет 극값 ⇔ у f′(x) = 0 два различных корня ⇔ D > 0.

Решение
Шаг 1. f′(x) = 3x² + 6ax + (6a + 9) Шаг 2. D/4 = (3a)² − 3(6a + 9) = 9a² − 18a − 27 > 0 Шаг 3. a² − 2a − 3 > 0 → (a − 3)(a + 1) > 0 → a < −1 или a > 3 Шаг 4. наименьшее натуральное: a = 4 (a = 3 не подходит, там D = 0)

Ответ: ③ 4

303중하

함수 f(x) = x³ + ax² + (a² − 8a)x + 1이 극값을 갖지 않도록 하는 모든 실수 a의 값의 범위가 a ≤ α 또는 a ≥ β일 때, α + β의 값은?

Перевод: функция не имеет экстремумов при a ≤ α или a ≥ β. Найдите α + β.

① 10② 11③ 12④ 13⑤ 14
Подсказка

«극값을 갖지 않는다» → D ≤ 0. Со знаком «равно».

Решение
Шаг 1. f′(x) = 3x² + 2ax + (a² − 8a) Шаг 2. D/4 = a² − 3(a² − 8a) = −2a² + 24a ≤ 0 Шаг 3. a² − 12a ≥ 0 → a(a − 12) ≥ 0 → a ≤ 0 или a ≥ 12 Шаг 4. α = 0, β = 12 → α + β = 12

Ответ: ③ 12

304중하

함수 f(x) = x³ + (k − 3)x² + (2 − k)x − 3이 0 < x < 1에서 극댓값을 갖고, 1 < x < 2에서 극솟값을 갖도록 하는 실수 k의 값의 범위가 a < k < b이다. 이때 a + b의 값을 구하시오.

Перевод: функция имеет максимум на (0, 1) и минимум на (1, 2) при a < k < b. Найдите a + b.

Подсказка

У кубической с положительным старшим коэффициентом сначала идёт 극대 (знак f′: + → −), потом 극소 (− → +). Значит, парабола f′ должна быть: f′(0) > 0, f′(1) < 0, f′(2) > 0.

Решение
Шаг 1. f′(x) = 3x² + 2(k − 3)x + (2 − k) Шаг 2. f′(0) = 2 − k > 0 → k < 2 Шаг 3. f′(1) = 3 + 2k − 6 + 2 − k = k − 1 < 0 → k < 1 Шаг 4. f′(2) = 12 + 4k − 12 + 2 − k = 3k + 2 > 0 → k > −2/3 Шаг 5. вместе: −2/3 < k < 1 → a + b = −2/3 + 1 = 1/3

Ответ: 1/3

305중하

함수 f(x) = 2x⁴ + ax³ + 5x²이 극댓값을 갖도록 하는 자연수 a의 최솟값은?

Перевод: найдите наименьшее натуральное a, при котором функция имеет максимум.

① 5② 6③ 7④ 8⑤ 9
Подсказка

Это 사차함수. Вынеси x из f′(x). 극대 будет, только если у f′(x) = 0 три различных корня.

Решение
Шаг 1. f′(x) = 8x³ + 3ax² + 10x = x(8x² + 3ax + 10) Шаг 2. один корень x = 0; нужны ещё два различных корня у 8x² + 3ax + 10, не равных 0 Шаг 3. 0 не корень (10 ≠ 0) ✓; D = 9a² − 320 > 0 → a² > 35.5… Шаг 4. a = 5: 25 ✗, a = 6: 36 > 35.5 ✓

При a = 6 корни f′: −1.25, −1, 0. Знаки: − | + | − | +, значит в x = −1 есть 극대.

Ответ: ② 6

450중하 · средняяключевая задача2017년 6월 고3 10번

닫힌구간 [−1, 3]에서 함수 f(x) = x³ − 3x + 5의 최솟값은?

Перевод: найдите наименьшее значение функции f(x) = x³ − 3x + 5 на отрезке [−1, 3].

① 1② 2③ 3④ 4⑤ 5
Разбор
Шаг 1. f′(x) = 3x² − 3 = 3(x + 1)(x − 1) → x = −1, 1 Шаг 2. x = −1 — это сам конец отрезка, x = 1 — внутри ✓ Шаг 3. f(−1) = −1 + 3 + 5 = 7, f(1) = 1 − 3 + 5 = 3, f(3) = 27 − 9 + 5 = 23 Шаг 4. наименьшее: 3 (при x = 1)

Внутри отрезка только один экстремум (극소 в x = 1), поэтому по 참고 он сразу и есть 최솟값. Кстати, 최댓값 = 23 на конце.

Перевод: на отрезке [0, 3] наибольшее значение функции f(x) = x³ − 12x + k равно 40. Найдите наименьшее значение (k — константа).

Разбор

Ответ: 24
