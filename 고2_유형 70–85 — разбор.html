70

부정적분의 정의

Определение неопределённого интеграла

Ключ · 핵심

F(x)가 f(x)의 한 부정적분이다 ⇔ F′(x) = f(x) ⇔ ∫f(x)dx = F(x) + C

«한 부정적분» = функция, производная которой равна f. Значит, чтобы из F получить f, надо дифференцировать, а не интегрировать.

515대표 유제하

함수 f(x)의 부정적분 중 하나가 x³ − 2x² + 1일 때, 함수 f(x)는?

Перевод: одна из первообразных функции f(x) равна x³ − 2x² + 1. Найдите f(x).

① x³ − 2x²② x³ + 2x²③ 3x² − 4x④ 3x² + 4x⑤ 6x − 4
Разбор

Как думать. Дано F, ищем f. Стрелка «부정적분» идёт от f к F. Нам нужно идти обратно — значит, дифференцируем.

Шаг 1. Запиши определение. F(x) = x³ − 2x² + 1 ⇒ f(x) = F′(x) Шаг 2. Дифференцируй по членам. (x³)′ = 3x², (−2x²)′ = −4x, (1)′ = 0 Шаг 3. Собери. f(x) = 3x² − 4x
Ловушка

Вариант ① — это почти сама F, а ⑤ — вторая производная (продифференцировали два раза). Константа +1 при дифференцировании исчезает — поэтому у одной f бесконечно много первообразных.

Ответ: ③ 3x² − 4x

521대표 유제하

다항함수 f(x)에 대하여 ddx∫f(x)dx = 4x³ + 2x일 때, f(2)의 값을 구하시오.

Перевод: производная от неопределённого интеграла f равна 4x³ + 2x. Найдите f(2).

Разбор

Как думать. Смотрим на порядок операций: внутри ∫, снаружи d/dx. Последней делается производная — она «съедает» интеграл. Значит, левая часть — это просто f(x).

Шаг 1. Упрости левую часть. ddx∫f(x)dx = f(x) Шаг 2. Приравняй. f(x) = 4x³ + 2x Шаг 3. Подставь. f(2) = 4·8 + 2·2 = 32 + 4 = 36
Ловушка

Не нужно интегрировать 4x³ + 2x! Частая ошибка: ученик видит ∫ и сразу пишет x⁴ + x² + C. Правая часть — это уже готовая f(x).

Ответ: 36

524대표 유제중하

함수 f(x)에 대하여 ∫{ddxf(x)}dx = 2x³ − 9x + C이고, f(2) = 12일 때, f(1)의 값은? (단, C는 적분상수이다.)

Перевод: интеграл от производной f равен 2x³ − 9x + C, и f(2) = 12. Найдите f(1).

① 1② 3③ 5④ 7⑤ 9
Разбор

Как думать. Последним стоит ∫ ⇒ левая часть равна f(x) + C. Значит f(x) отличается от 2x³ − 9x на какую-то неизвестную константу. Её найдём из условия f(2) = 12.

Шаг 1. Убери ∫ и d/dx. f(x) + C = 2x³ − 9x + C Шаг 2. Запиши f с неизвестной константой. f(x) = 2x³ − 9x + k (k — какое-то число) Шаг 3. Найди k из условия. f(2) = 16 − 18 + k = −2 + k = 12 ⇒ k = 14 Шаг 4. Ответ на вопрос. f(1) = 2 − 9 + 14 = 7
Ловушка

Нельзя сказать «C слева и справа сокращаются, значит f(x) = 2x³ − 9x». Тогда f(2) = −2 ≠ 12 — противоречие. Константа у f есть, и её надо находить по условию.

Ответ: ④ 7

Проверка интеграла дифференцированием

Ключ · 핵심

∫f(x)dx = g(x) 꼴이 조건으로 주어지면 양변을 미분하여 f(x)를 구한다.

Если дано ∫ f(x)dx = g(x), продифференцируй обе части: f(x) = g′(x). И наоборот: чтобы проверить равенство ∫ h dx = G + C, достаточно проверить G′ = h.

528대표 유제중

다음 보기 중 미분가능한 함수 f(x)에 대하여 옳은 것만을 있는 대로 고른 것은? (단, C는 적분상수)
ㄱ. ∫f′(x)dx + ∫x²dx = f(x) + 13x³ + C
ㄴ. ∫f′(x){f(x)}²dx = {f(x)}³ + C
ㄷ. ∫x²f(x)dx + ∫x³f′(x)dx = x³f(x) + C

Перевод: выберите все верные равенства.

① ㄱ② ㄴ③ ㄱ, ㄷ④ ㄴ, ㄷ⑤ ㄱ, ㄴ, ㄷ
Разбор

Как думать. Интегрировать такие выражения напрямую мы не умеем. Зато умеем дифференцировать! Берём правую часть, дифференцируем и сравниваем с тем, что стоит под ∫.

ㄱ. (f(x) + ⅓x³)′ = f′(x) + x² — совпадает с подынтегральными функциями f′(x) и x². Верно ✓ ㄴ. ({f(x)}³)′ = 3{f(x)}²·f′(x) (производная сложной функции). Под ∫ стоит f′(x){f(x)}² — в 3 раза меньше. Неверно ✗     Правильно было бы: ⅓{f(x)}³ + C. ㄷ. (x³f(x))′ = 3x²f(x) + x³f′(x) (производная произведения). Под ∫ стоит x²f(x) + x³f′(x) — не хватает тройки перед x²f(x). Неверно ✗
Ловушка

В ㄷ всё выглядит «почти как» производная произведения (uv)′ = u′v + uv′. Проверяй коэффициенты: (x³)′ = 3x², а не x².

Ответ: ① ㄱ

74

부정적분의 계산

Вычисление неопределённого интеграла

Ключ · 핵심

∫xⁿdx = 1n + 1xⁿ⁺¹ + C,   ∫1dx = x + C
∫kf(x)dx = k∫f(x)dx,   ∫{f(x) ± g(x)}dx = ∫f(x)dx ± ∫g(x)dx (복호동순)

Степень +1, делим на новую степень. Константу выносим, сумму интегрируем по частям. И главное: несколько интегралов по dx можно сложить в один — часто так всё упрощается.

529대표 유제중하

함수 f(x)가 f(x) = ∫(x + 1)(x² − x + 1)dx − ∫(x − 1)(x² + x + 1)dx이고, f(2) = 10일 때, f(1)의 값을 구하시오.

Перевод: f задана разностью двух интегралов, f(2) = 10. Найдите f(1).

Разбор

Как думать. Можно раскрыть каждый интеграл отдельно — получится длинно. Умнее: интегралы по одному dx объединить в один, и подынтегральная функция сильно упростится.

Шаг 1. Один интеграл. f(x) = ∫{(x + 1)(x² − x + 1) − (x − 1)(x² + x + 1)}dx Шаг 2. Формулы куба. (x + 1)(x² − x + 1) = x³ + 1, (x − 1)(x² + x + 1) = x³ − 1 Шаг 3. Разность. (x³ + 1) − (x³ − 1) = 2 Шаг 4. Интегрируй. f(x) = ∫2dx = 2x + C Шаг 5. Найди C. f(2) = 4 + C = 10 ⇒ C = 6 Шаг 6. f(1) = 2 + 6 = 8
Формулы, которые здесь пригодились

a³ + b³ = (a + b)(a² − ab + b²),   a³ − b³ = (a − b)(a² + ab + b²)

Ответ: 8

75

도함수가 주어질 때 함수 구하기

Дана производная — найти функцию

Ключ · 핵심 — 3 шага

(i) f(x) = ∫f′(x)dx로 적분상수를 포함한 식으로 나타낸다.
(ii) 주어진 함숫값이나 조건으로 적분상수를 구한다.
(iii) 구한 적분상수를 (i)의 식에 대입한다.

(i) Интегрируем f′ — получаем f с C. (ii) Из данного значения находим C. (iii) Подставляем C обратно.

538대표 유제중하

함수 f(x)에 대하여 f′(x) = x³ − 8x² + 2x + 4이고, f(0) = 3일 때, f(−2)의 값을 구하시오.

Перевод: производная — дробь; f(0) = 3. Найдите f(−2).

Разбор

Как думать. Дробь интегрировать мы не умеем. Значит, её надо сократить. Числитель x³ − 8 = x³ − 2³ — разность кубов, и одна из скобок совпадёт со знаменателем.

Шаг 1. Разложи числитель. x³ − 8 = (x − 2)(x² + 2x + 4) Шаг 2. Сократи. f′(x) = (x − 2)(x² + 2x + 4)x² + 2x + 4 = x − 2     Можно: x² + 2x + 4 = (x + 1)² + 3 > 0 — знаменатель никогда не равен 0. Ключ · 핵심

572대표 유제중

정적분의 계산(1) 적분 구간이 같은 경우

Одинаковые пределы — один интеграл

Ключ · 핵심

∫baf(x)dx ± ∫bag(x)dx = ∫ba{f(x) ± g(x)}dx (복호동순)

Если пределы одинаковые — сначала объединяем подынтегральные функции, потом считаем. Если пределы перевёрнуты — сначала переворачиваем: ∫ab = −∫ba.

573대표 유제하

∫20(x + 2)²dx + ∫02(x − 2)²dx의 값을 구하시오.

Разбор

Как думать. Пределы «почти одинаковые» — во втором они перевёрнуты. Переворачиваем, меняя знак, и получаем один интеграл.

Шаг 1. Переверни второй. ∫02(x − 2)²dx = −∫20(x − 2)²dx Шаг 2. Один интеграл. ∫20{(x + 2)² − (x − 2)²}dx Шаг 3. Упрости. (x + 2)² − (x − 2)² = (x² + 4x + 4) − (x² − 4x + 4) = 8x Шаг 4. Посчитай. ∫208xdx = [4x²]20 = 16
Быстрый приём

(a + b)² − (a − b)² = 4ab. Здесь a = x, b = 2: сразу 8x.

Ловушка

Если не перевернуть пределы и просто сложить (x + 2)² + (x − 2)², получится неправильный ответ. Сначала смотри на пределы — потом на функции.

Ответ: 16

85

정적분의 계산(2) 피적분함수가 같은 경우

Одна функция — склеиваем промежутки

Ключ · 핵심

∫caf(x)dx + ∫bcf(x)dx = ∫baf(x)dx

Функция одна и та же, а промежутки идут «цепочкой»: конец первого = начало второго. Тогда их можно склеить в один. 주의: это верно при любом порядке чисел a, b, c.

Аналогия

Поездка Москва → Казань, потом Казань → Екатеринбург = Москва → Екатеринбург. Промежуточная станция «сокращается». Если едешь в обратную сторону — расстояние со знаком минус.

579대표 유제하

정적분 ∫5−2(x³ + 4x² + 7x − 5)dx + ∫25(x³ + 4x² + 7x − 5)dx를 계산하면?

① 1/2② 2/3③ 5/4④ 4/3⑤ 3/2
Разбор

Как думать. Функции одинаковые. Смотрим на пределы: −2 → 5, потом 5 → 2. Станция 5 — общая, склеиваем: −2 → 2. Получился симметричный промежуток — ещё одно упрощение.

Шаг 1. Склей. ∫5−2 + ∫25 = ∫2−2(x³ + 4x² + 7x − 5)dx Шаг 2. Симметричный промежуток. Нечётные степени x³ и 7x дают 0, чётные удваиваются:     = 2∫20(4x² − 5)dx Шаг 3. Посчитай. 2[⁴⁄₃x³ − 5x]20 = 2(323 − 10) = 2·23 = 43
Проверка без «чётных/нечётных»

F(x) = ¼x⁴ + ⁴⁄₃x³ + ⁷⁄₂x² − 5x. F(2) = 4 + 32/3 + 14 − 10 = 56/3, F(−2) = 4 − 32/3 + 14 + 10 = 52/3. Разность = 4/3 ✓

Ловушка

Не надо считать два интеграла по 7 и 3 единицы длиной — это долго и легко ошибиться. Сначала всегда ищи «общую станцию».

Ответ: ④ 4/3
