정적분의 계산(3) 구간에 따라 다르게 정의된 함수

Функция «по кускам» — режем интеграл в точке стыка

Ключ · 핵심

함수 f(x) = g(x)   (x ≥ c)h(x)   (x < c)가 닫힌구간 [a, b]에서 연속이고, a < c < b일 때

∫baf(x)dx = ∫cah(x)dx + ∫bcg(x)dx

У функции две формулы: слева от c одна, справа другая. Значит и интеграл считаем двумя частями: от a до стыка c берём левую формулу, от c до b — правую.

Аналогия

Такси: первые 2 км стоят по одному тарифу, дальше — по другому. Цену всей поездки нельзя посчитать одной формулой. Считаем отдельно «до 2 км» и «после 2 км», потом складываем.

587대표 유제중하

f(x) = 3x² + x   (x ≥ 1)5x³ − 1   (x < 1)일 때, 정적분 ∫20xf(x)dx의 값을 구하시오.

Разбор

Как думать. Под интегралом стоит не f(x), а x·f(x). Поэтому сначала умножаем каждый кусок на x. Стык x = 1 лежит внутри [0, 2] — режем интеграл в точке 1.

Шаг 1. Умножь каждый кусок на x. при x < 1: x(5x³ − 1) = 5x⁴ − x;   при x ≥ 1: x(3x² + x) = 3x³ + x² Шаг 2. Разрежь в точке 1. ∫20xf(x)dx = ∫10(5x⁴ − x)dx + ∫21(3x³ + x²)dx Шаг 3. Левая часть. [x⁵ − x²2]10 = 1 − 12 = 12 Шаг 4. Правая часть. [3x⁴4 + x³3]21 = (12 + 83) − (34 + 13) = 443 − 1312 = 16312 Шаг 5. Сложи. 12 + 16312 = 612 + 16312 = 16912
Ловушка

Легко взять не ту строку. На [0, 1) действует условие x < 1, то есть нижняя строка 5x³ − 1. Всегда читай условие в скобках, а не порядок строк.

Ответ: 16912

정적분의 계산(4) 절댓값 기호를 포함한 함수

Модуль под интегралом — сначала снимаем модуль

Ключ · 핵심

(ⅰ) 절댓값 기호 안의 식의 값이 0이 되도록 하는 x의 값을 기준으로 적분 구간을 나눈다.

(ⅱ) ∫baf(x)dx = ∫caf(x)dx + ∫bcf(x)dx임을 이용하여 정적분을 계산한다.

Модуль интегрировать «в лоб» нельзя. Находим, где выражение внутри модуля равно 0. В этой точке режем промежуток. На каждом куске модуль снимается: где выражение ≥ 0 — оставляем как есть, где < 0 — меняем знак.

Аналогия

Модуль — как зеркальный пол: всё, что было под осью x, отражается наверх. Поэтому интеграл от модуля — это всегда «чистая» площадь, без минусов.

589대표 유제하

∫40|x − 3|dx의 값을 구하시오.

Разбор

Как думать. Внутри модуля x − 3. Оно равно 0 при x = 3, и 3 лежит внутри [0, 4]. Значит режем в точке 3.

Шаг 1. Сними модуль. при x < 3: |x − 3| = −(x − 3) = −x + 3;   при x ≥ 3: |x − 3| = x − 3 Шаг 2. Разрежь в точке 3. ∫40|x − 3|dx = ∫30(−x + 3)dx + ∫43(x − 3)dx Шаг 3. Левая часть. [−x²2 + 3x]30 = −92 + 9 = 92 Шаг 4. Правая часть. [x²2 − 3x]43 = (8 − 12) − (92 − 9) = −4 + 92 = 12 Шаг 5. Сложи. 92 + 12 = 5
Ловушка

Если просто посчитать ∫40(x − 3)dx без модуля, получится −4. Интеграл от модуля не может быть отрицательным — это сигнал ошибки.

Ответ: 5

590중하

∫2−2|x² − 2x − 3|dx의 값을 구하시오.

Подсказка

Разложи: x² − 2x − 3 = (x + 1)(x − 3). Внутри [−2, 2] лежит только корень x = −1. На [−2, −1] выражение положительное, на [−1, 2] — отрицательное (меняй знак).

591중하

∫2−2|x² + 2x − 3|dx의 값은?

① 10② 32/3③ 34/3④ 12⑤ 38/3
Подсказка

x² + 2x − 3 = (x + 3)(x − 1). Корень −3 вне промежутка, внутри только x = 1. Проверь знак в точке x = 0.

592중하

∫60|x² − 4x|dx + ∫40(x² − 4x)dx의 값은?

① 26/3② 28/3③ 10④ 32/3⑤ 34/3
Подсказка

На [0, 4] выражение x² − 4x ≤ 0, значит там |x² − 4x| = −(x² − 4x). Разрежь первый интеграл в точке 4 — и кусок от 0 до 4 сократится со вторым интегралом.

593중하

정적분 ∫60(2x + |2x − 4|)dx의 값을 구하시오.

Подсказка

2x − 4 = 0 при x = 2. На [0, 2]: 2x − (2x − 4) = 4 — просто число. На [2, 6]: 2x + (2x − 4) = 4x − 4.

함수 f(x) = |x + 2| + |x − 2| + |x|의 최솟값 a에 대하여 정적분 ∫a0f(x)dx의 값은?

① 28② 57/2③ 29④ 59/2⑤ 30
Подсказка

f(x) — сумма расстояний от x до точек −2, 0, 2. Она наименьшая в средней точке x = 0, значит a = f(0). Потом сними модули на [0, 2] и на [2, a] отдельно.

우함수·기함수의 정적분(1) 피적분함수가 주어진 경우

Пределы −a и a: нечётные степени исчезают

Ключ · 핵심

(1) 다항함수 f(x)가 짝수 차수의 항과 상수항으로만 이루어져 있다. ⇨ f(−x) = f(x), 우함수 ⇨ ∫a−af(x)dx = 2∫a0f(x)dx

(2) 다항함수 f(x)가 홀수 차수의 항으로만 이루어져 있다. ⇨ f(−x) = −f(x), 기함수 ⇨ ∫a−af(x)dx = 0

Увидел пределы вида −a и a — раскрой скобки и раздели слагаемые. Нечётные степени (x, x³, x⁵) дают 0, их можно сразу зачеркнуть. Чётные степени и числа (x², x⁴, 5) считаем от 0 до a и умножаем на 2.

Аналогия

Качели-балансир. У нечётной функции слева «яма» точно такого же размера, как «горка» справа — они уравновешиваются, в сумме 0. У чётной функции слева и справа одинаковые «горки» — считаем одну и удваиваем.

595대표 유제하

∫1−1(x + 1)(6x + 5)dx의 값을 구하시오.

Разбор

Как думать. Пределы −1 и 1 симметричны. Раскрываем скобки и смотрим на степени.

Шаг 1. Раскрой скобки. (x + 1)(6x + 5) = 6x² + 11x + 5 Шаг 2. Зачеркни нечётную степень. 11x — 홀수 차수, её интеграл от −1 до 1 равен 0 Шаг 3. Остальное — удвой. ∫1−1(6x² + 5)dx = 2∫10(6x² + 5)dx Шаг 4. Посчитай. 2[2x³ + 5x]10 = 2·7 = 14
Почему это удобно

Нижний предел стал 0. При подстановке нуля всё обнуляется, и не нужно возиться с минусами.

Ловушка

Число 5 — это 5x⁰, чётная степень. Его нельзя зачёркивать. И не забудь множитель 2.

Ответ: 14

우함수·기함수의 정적분(2) 피적분함수가 주어지지 않은 경우

Формулы нет, есть только условие f(−x) = ±f(x)

Ключ · 핵심

(1) f(−x) = f(x) ⇨ 우함수 ⇨ 그래프는 y축에 대하여 대칭 ⇨ ∫a−af(x)dx = 2∫a0f(x)dx

(2) f(−x) = −f(x) ⇨ 기함수 ⇨ 그래프는 원점에 대하여 대칭 ⇨ ∫a−af(x)dx = 0

(우)·(우) = (우),   (우)·(기) = (기),   (기)·(기) = (우)

Формула функции не дана, но условие f(−x) = f(x) или f(−x) = −f(x) говорит, чётная она или нечётная. Произведения работают как знаки: чётная — это «плюс», нечётная — «минус». Например, x·f(x) при нечётной f — это «минус на минус», то есть чётная.

602대표 유제중하

실수 전체의 집합에서 미분가능한 함수 f(x)의 도함수 f′(x)가 f′(x) = 2x   (x < 0)a(x² − 2x)   (x ≥ 0)이다. ∫4−1f′(x)dx = 15일 때, 상수 a의 값을 구하시오.

Шаг 1. Разрежь в точке 0. ∫4−1f′(x)dx = ∫0−12xdx + ∫40a(x² − 2x)dx Шаг 2. Левая часть. [x²]0−1 = 0 − 1 = −1 Шаг 3. Правая часть. a[x³3 − x²]40 = a(643 − 16) = 163a Шаг 4. Уравнение. −1 + 163a = 15 ⇒ 163a = 16 ⇒ a = 3

В шаге 2: [x²] от −1 до 0 — это 0² − (−1)² = −1, а не +1. «Верх минус низ».

주기함수의 정적분

Периодическая функция — считаем периоды

Ключ · 핵심

연속함수 f(x)가 모든 실수 x에 대하여 f(x + k) = f(x) (k는 상수)를 만족시킬 때

(1) ∫baf(x)dx = ∫b+ka+kf(x)dx = ∫b+2ka+2kf(x)dx = ⋯

(2) ∫a+kaf(x)dx = ∫b+kbf(x)dx

График повторяется через каждые k. Поэтому (1) промежуток можно сдвинуть на период — интеграл не изменится; (2) интеграл по любому промежутку длиной в один период один и тот же, откуда бы ни начинать.

Аналогия

Расписание уроков повторяется каждую неделю. Сколько уроков за любые 7 дней подряд? Столько же, сколько с понедельника по воскресенье — неважно, с какого дня считать. А за 3 недели — в 3 раза больше.

604대표 유제중하

연속함수 f(x)가 임의의 실수 x에 대하여 f(x) = f(x + 2)를 만족시키고 ∫31f(x)dx = 3일 때, 정적분 ∫5−1f(x)dx의 값을 구하시오.

Разбор

Как думать. f(x) = f(x + 2) — период равен 2. Смотрим на длину промежутков: сколько периодов в каждом.

Шаг 1. Длина данного промежутка. [1, 3]: 3 − 1 = 2 — ровно один период. Значит интеграл по одному периоду равен 3. Шаг 2. Длина нужного промежутка. [−1, 5]: 5 − (−1) = 6 = 3·2 — три периода Шаг 3. Разбей на периоды. ∫5−1 = ∫1−1 + ∫31 + ∫53 = 3 + 3 + 3 Шаг 4. Ответ. 3·3 = 9

Ответ: 32

95

정적분으로 정의된 함수의 극한(1) lim (1/x)∫f(t)dt 꼴

Предел «интеграл, делённый на маленькую длину»

Ключ · 핵심

함수 f(x)의 한 부정적분을 F(x)라 할 때

limx→01x∫x+aaf(t)dt = limx→0F(x + a) − F(a)x = F′(a) = f(a)

limh→01h∫a+qha+phf(t)dt = (q − p)f(a)   (p, q는 상수)

Интеграл по очень короткому промежутку, делённый на длину этого промежутка. Это определение производной первообразной F в точке a, а F′ = f. Поэтому ничего интегрировать не нужно: ответ — значение функции под интегралом в точке a (нижний предел).

Аналогия

Спидометр. Путь за крошечное время, делённый на это время, — мгновенная скорость. Здесь то же самое: площадь над крошечным отрезком, делённая на его длину, — это высота графика в этой точке, то есть f(a).
