1 · 복습 (разминка)

Вспомним производную

Сегодня всё время будем «идти назад» от производной. Поэтому сначала два факта о 미분, которые надо помнить без раздумий.

Степень

(xⁿ)′ = n·xⁿ⁻¹

Степень уменьшается на 1, старая степень выходит вперёд множителем.

Константа

(5)′ = 0, (C)′ = 0

Любое число при дифференцировании исчезает. Это причина появления +C сегодня.

Связь с прошлым уроком

Положение x(t) → 미분 → скорость v(t). Сегодня вопрос обратный: знаем скорость v(t). Где находится точка?

2 · 부정적분

Что такое неопределённый интеграл

Аналогия · спидометр без навигатора

Ты едешь по трассе, навигатор сломался, работает только спидометр. Весь час он показывал 60 км/ч. Где ты сейчас? Ты знаешь, что проехал 60 км, но не знаешь, откуда стартовал. Если старт был на 10-м километре, ты на 70-м; если на 100-м — на 160-м.

Скорость (производная) одна и та же, а положений (исходных функций) много. Они отличаются только сдвигом — числом старта. В математике этот сдвиг называется C.

Учебник · стр. 134 · ① 부정적분

(1) 함수 F(x)의 도함수가 f(x)일 때, 즉 F′(x) = f(x)일 때, 함수 F(x)를 f(x)의 부정적분이라 하고, 이것을 기호로 ∫f(x)dx와 같이 나타낸다.
(2) 함수 f(x)의 부정적분 중 하나를 F(x)라 하면 ∫f(x)dx = F(x) + C (C는 상수)이다.
이때 C를 적분상수, x를 적분변수, f(x)를 피적분함수라 한다.

(1) Если производная функции F(x) равна f(x), то есть F′(x) = f(x), то F(x) называют неопределённым интегралом (первообразной) функции f(x) и обозначают ∫f(x)dx.
(2) Если F(x) — одна из первообразных, то ∫f(x)dx = F(x) + C, где C — константа. C — постоянная интегрирования, x — переменная интегрирования, f(x) — подынтегральная функция.

참고

함수 f(x)의 부정적분을 구하는 것을 함수 f(x)를 적분한다고 하고, 그 계산법을 적분법이라 한다.

Найти неопределённый интеграл = «проинтегрировать» функцию. Способ вычисления называется 적분법.

∫ … dx

Знак ∫ и dx — как скобки: открыли и закрыли. Между ними стоит 피적분함수.

dx

Показывает 적분변수: интегрируем «по x». Если стоит dt, то переменная — t.

+ C

적분상수. Ответ без +C в задаче «найти 부정적분» считается неполным.

예시 · пример из учебника

(x²)′ = 2x, (x² + 1)′ = 2x, (x² + 2)′ = 2x, … 이므로 x², x² + 1, x² + 2, …은 모두 2x의 부정적분이다. 따라서 함수 2x의 부정적분은 무수히 많고 상수항만 다르며, 이를 x² + C의 꼴로 나타낼 수 있다. 즉, ∫2x dx = x² + C이다.

Перевод: у x², x² + 1, x² + 2 одна и та же производная 2x. Значит, первообразных у 2x бесконечно много, они отличаются только свободным членом. Все сразу записываем как x² + C.

x², x² + 1, x² + 2, …много функций
→도함수
2xодна производная
→부정적분
x² + Cвсе сразу
Внимание

«한 부정적분» (одна первообразная) — это конкретная функция без +C, например x² + 3. А «부정적분» в ответе — всегда с +C. В задачах вида «f(x)의 한 부정적분이 x³ + x² …» сразу дифференцируй: f = производная этой функции.

3 · 부정적분과 미분의 관계

Интеграл и производная гасят друг друга. Почти

Аналогия · фото и стирание подписи

Представь: 미분 — это машинка, которая стирает с листа подпись внизу (константу). 적분 — машинка, которая возвращает текст, но подпись придумать не может и пишет «C».

Сначала вернули текст, потом стёрли подпись — получили ровно то, что было. Сначала стёрли подпись, потом вернули текст — внизу стоит «C» вместо настоящей подписи.

Учебник · стр. 134 · ② 부정적분과 미분의 관계

(1) ddx{∫f(x)dx} = f(x)
(2) ∫{ddxf(x)}dx = f(x) + C (단, C는 적분상수이다.)

(1) Сначала интегрируем, потом дифференцируем — получаем ровно f(x), без C.
(2) Сначала дифференцируем, потом интегрируем — получаем f(x) + C.

주의 · главная ловушка

ddx{∫f(x)dx} ≠ ∫{ddxf(x)}dx

Смотри, какая операция последняя (снаружи). Снаружи d/dx → C нет. Снаружи ∫ → +C есть. Ошибка в одном C = неправильный ответ.

예시 · два порядка на одной функции
(1) d/dx {∫(x³ − 2x)dx} = x³ − 2x (2) ∫{d/dx (x³ − 2x)}dx = ∫(3x² − 2)dx = x³ − 2x + C

Во втором случае C потом находят из условия, например f(0) = 7 ⇒ C = 7 (это задача 497).

4 · 함수 y = xⁿ의 부정적분

Главная формула: степень вверх, делим на новую степень

Аналогия · перемотка назад

Производная делает два шага: «вынести степень вперёд» и «уменьшить степень на 1». Интеграл — это видео, пущенное назад: сначала увеличиваем степень на 1, потом делим на эту новую степень (вместо умножения).

Учебник · стр. 134 · ③

(1) ∫xⁿdx = 1n + 1xⁿ⁺¹ + C (단, n은 자연수이고, C는 적분상수이다.)
(2) ∫1dx = x + C (단, C는 적분상수이다.)

(1) Для натурального n: интеграл от xⁿ равен xⁿ⁺¹, делённому на n + 1, плюс C. (2) Интеграл от 1 равен x + C.

참고

∫1dx를 간단히 ∫dx로 나타내기도 한다.

Единицу внутри часто не пишут: ∫dx значит ∫1dx.

예시 · из учебника + проверка
Шаг 1. ∫x dx = x¹⁺¹/(1+1) + C = ½x² + C Шаг 2. ∫x² dx = x²⁺¹/(2+1) + C = ⅓x³ + C Шаг 3. ∫5 dx = 5x + C Проверка. (½x² + C)′ = x ✓   (⅓x³ + C)′ = x² ✓   (5x + C)′ = 5 ✓

Привычка на всю главу: посчитал интеграл — продифференцируй в уме. Если получилась исходная функция, ответ верный.

5 · 함수의 실수배, 합, 차의 부정적분

Многочлен интегрируем по одному слагаемому

Учебник · стр. 134 · ④

두 함수 f(x), g(x)의 부정적분이 존재할 때
(1) ∫kf(x)dx = k∫f(x)dx (단, k는 0이 아닌 실수이다.)
(2) ∫{f(x) + g(x)}dx = ∫f(x)dx + ∫g(x)dx
(3) ∫{f(x) − g(x)}dx = ∫f(x)dx − ∫g(x)dx

Если у f и g есть первообразные: (1) число-множитель выносим за знак интеграла (k ≠ 0); (2) интеграл суммы = сумма интегралов; (3) интеграл разности = разность интегралов. 참고: (2), (3) верны и для трёх и более функций.

예시 · многочлен

∫(3x² − 4x + 5)dx

Шаг 1. Разбить. 3∫x²dx − 4∫x dx + ∫5 dx Шаг 2. Формула xⁿ. 3·⅓x³ − 4·½x² + 5x Шаг 3. Один общий C. x³ − 2x² + 5x + C Проверка. (x³ − 2x² + 5x + C)′ = 3x² − 4x + 5 ✓

Константы от каждого слагаемого сливаются в одну C — пишем её один раз в конце.

Внимание · произведение

Для произведения такого правила нет: ∫f(x)g(x)dx ≠ ∫f(x)dx · ∫g(x)dx. Сначала раскрой скобки, потом интегрируй по слагаемым.

Пример: ∫(x − 3)(x² + 3x + 9)dx = ∫(x³ − 27)dx = ¼x⁴ − 27x + C. Здесь помогла формула (a − b)(a² + ab + b²) = a³ − b³.

6 · 실험실 (лаборатория)

Найди нужную C

Дано: f(x) = x² − 1. Её первообразные: F(x) = ⅓x³ − x + C. Двигай C — кривая поднимается и опускается. Задача: подобрать C, чтобы кривая прошла через точку (3, 7). Двигай x₀ — увидишь, что наклон касательной от C не зависит.

Константа C−2
значение F(3) = 6 + C4
наклон в x₀: f(x₀)1.56
Что заметить
  • Все кривые — копии одной, сдвинутые по вертикали. Сдвиг = C.
  • Касательные при одном x₀ параллельны: наклон = f(x₀), он один для всех.
  • Одно условие «점 (3, 7)을 지난다» выбирает ровно одну кривую: F(3) = 7 ⇒ 6 + C = 7 ⇒ C = 1.
7 · 풀이 순서 (рецепт)

Как решать задачи на неопределённый интеграл

Тип A · дано f′ и точка
  1. Проинтегрируй f′(x) по слагаемым.
  2. Допиши +C.
  3. Подставь условие (f(0) = 1, «점을 지난다») → найди C.
  4. Посчитай то, что спрашивают.
Тип B · d/dx и ∫ вместе
  1. Посмотри, какая операция снаружи.
  2. Снаружи d/dx → просто убери оба знака.
  3. Снаружи ∫ → убери оба знака и добавь +C.
  4. Или продифференцируй обе части равенства.
Тип C · внутри f(1), f(0), k
  1. f(1) — это просто число. Обозначь a = f(1).
  2. Проинтегрируй, как обычно, с a и C.
  3. Составь уравнения: «f(1) = a» и данное условие.
  4. Иногда помогает подставить x = 0 или x = 1 в равенство.
Чаще всего ошибаются здесь

Шаг «допиши +C». Без C ты не используешь условие f(0) = 1 и получаешь неправильный ответ, который почти всегда есть среди вариантов.

500중하ключевая задача

점 (1, 5)를 지나는 곡선 y = f(x) 위의 임의의 점 (x, y)에서의 접선의 기울기가 6x² − 6x + 4일 때, f(2)의 값을 구하시오.

Перевод: кривая y = f(x) проходит через точку (1, 5). В любой её точке (x, y) наклон касательной равен 6x² − 6x + 4. Найдите f(2).

501중하

다항함수 f(x)에 대하여 ddxF(x) = f(x)이고 F(x) = xf(x) − 2x²이 성립한다. f(0) = 2일 때, 함수 f(x)는?

Перевод: F′(x) = f(x) и F(x) = x·f(x) − 2x². При f(0) = 2 найдите f(x).

① −4x + 2② −2x + 2③ 2x + 2④ 4x + 2⑤ 6x + 2
Подсказка

Продифференцируй равенство. Для x·f(x) нужна производная произведения.

Разбор
Шаг 1. F′(x) = f(x) + x f′(x) − 4x Шаг 2. F′ = f ⇒ f(x) = f(x) + x f′(x) − 4x ⇒ x f′(x) = 4x ⇒ f′(x) = 4 Шаг 3. f(x) = 4x + C, f(0) = C = 2 ⇒ f(x) = 4x + 2

Ответ: ④ 4x + 2

502중하

모든 실수 x에서 미분가능한 함수 f(x)가 다음 조건을 만족시킨다.
(가) f(1) = 0   (나) f′(x) = k (x > 1), 2x − 3 (x < 1)
이때, f(4)의 값은? (단, k는 상수이다.)

Перевод: f дифференцируема везде. Производная задана кусками. Найдите f(4).

① −5② −4③ −3④ −2⑤ −1
Подсказка

미분가능 в точке 1 ⇒ производные слева и справа при x = 1 равны. Отсюда k.

Разбор
Шаг 1. f′ непрерывна в 1: k = 2·1 − 3 = −1 Шаг 2. при x > 1: f(x) = −x + C₁ Шаг 3. f(1) = 0 (f непрерывна) ⇒ −1 + C₁ = 0 ⇒ C₁ = 1 Шаг 4. f(4) = −4 + 1 = −3

Кусок x < 1 для f(4) не нужен — только для k.

Ответ: ③ −3

① 1② 3③ 5④ 7⑤ 9
Подсказка

То же, что 500, только буква t вместо x: f′(x) = −12x² + 4x.

Разбор
Шаг 1. f(x) = −4x³ + 2x² + C Шаг 2. f(1) = −4 + 2 + C = 1 ⇒ C = 3 Шаг 3. f(−1) = 4 + 2 + 3 = 9

Ответ: ⑤ 9

504중하

함수 f(x) = ∫(x − 3)(x² + 3x + 9)dx일 때, limh→0 f(1 + h) − f(1 − h)h의 값은?

Перевод: найдите предел для этой функции.

Подсказка

Интеграл считать не нужно! Предел равен 2f′(1), а f′ — это просто подынтегральная функция.

Разбор

563중하 · средняяключевая задача2021년 4월 고3 5번

함수 f(x)에 대하여 f′(x) = 2x + 4이고 f(−1) + f(1) = 0일 때, f(2)의 값은?

Перевод: f′(x) = 2x + 4 и f(−1) + f(1) = 0. Найдите f(2).

① 9② 10③ 11④ 12⑤ 13
Разбор

Условие не обязательно вида «f(0) = …». Любое равенство со значениями f даёт уравнение на C.

Тип B · связь d/dx и ∫

546중 · средняяключевая задача2018년 11월 고2 이과 10번

다항함수 f(x)가 ddx∫{f(x) − x² + 4}dx = ∫ddx{2f(x) − 3x + 1}dx를 만족시킨다. f(1) = 3일 때, f(0)의 값은?

Перевод: многочлен f(x) удовлетворяет равенству. f(1) = 3. Найдите f(0).

① −2② −1③ 0④ 1⑤ 2
Разбор
Шаг 1. Слева снаружи d/dx. → f(x) − x² + 4 (без C) Шаг 2. Справа снаружи ∫. → 2f(x) − 3x + 1 + C Шаг 3. f(x) − x² + 4 = 2f(x) − 3x + 1 + C ⇒ f(x) = −x² + 3x + 3 − C Шаг 4. f(1) = −1 + 3 + 3 − C = 5 − C = 3 ⇒ C = 2 Шаг 5. f(x) = −x² + 3x + 1 ⇒ f(0) = 1

Вся задача — это ловушка из раздела 3: с одной стороны C нет, с другой есть.

Ответ: ④ 1

Тип C · неизвестная константа внутри f′(x)

560중 · средняяключевая задача2023년 9월 고3 8번

다항함수 f(x)가 f′(x) = 6x² − 2f(1)x, f(0) = 4를 만족시킬 때, f(2)의 값은?

Перевод: многочлен f(x): производная содержит число f(1), и f(0) = 4. Найдите f(2).

① 5② 6③ 7④ 8⑤ 9
Разбор
Шаг 1. Обозначим число. a = f(1) ⇒ f′(x) = 6x² − 2ax Шаг 2. Интегрируем. f(x) = 2x³ − ax² + C Шаг 3. f(0) = 4. C = 4 Шаг 4. Смысл буквы a. f(1) = 2 − a + 4 = a ⇒ 2a = 6 ⇒ a = 3 Шаг 5. f(x) = 2x³ − 3x² + 4 ⇒ f(2) = 16 − 12 + 4 = 8

Главное — не пугаться f(1) внутри формулы. Это одно конкретное число. Шаг 4 — «замыкаем круг»: подставляем в f то самое значение, которым обозначили a.

Ответ: ④ 8
