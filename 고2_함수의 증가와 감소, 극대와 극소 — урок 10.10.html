1 · 복습 (повторение)

Разминка: знак наклона и дискриминант

НАКЛОН 미분계수 f′(a) = наклон касательной

f′(a) > 0: касательная идёт вверх ↗

f′(a) < 0: касательная идёт вниз ↘

f′(a) = 0: касательная горизонтальна →

ДИСКРИМИНАНТ Когда ax² + bx + c ≥ 0 для всех x?

Парабола ветвями вверх (a > 0) и не опускается ниже оси x, то есть касается оси или не пересекает её:

a > 0 и D ≤ 0

Для ≤ 0 всегда: a < 0 и D ≤ 0. Это понадобится в задачах 297, 389, 391.

2 · 함수의 증가와 감소

Возрастание и убывание: в гору или под гору

Пример из жизни

Ты идёшь по горной тропе слева направо (как по оси x). Если каждый следующий шаг выше предыдущего, ты идёшь в гору: функция 증가 (возрастает). Если каждый шаг ниже, ты спускаешься: 감소 (убывает).

Как понять по ногам, в гору ты идёшь или под гору? По наклону тропы прямо под тобой. Наклон под ногами — это и есть производная f′(x).

(1) Определение · 증가와 감소의 정의

Из учебника

함수 f(x)가 어떤 구간에 속하는 임의의 두 실수 x₁, x₂에 대하여
① x₁ < x₂일 때, f(x₁) < f(x₂)이면 함수 f(x)는 이 구간에서 증가한다고 한다.
② x₁ < x₂일 때, f(x₁) > f(x₂)이면 함수 f(x)는 이 구간에서 감소한다고 한다.

По-русски: возьмём любые два числа x₁ < x₂ из промежутка. ① Если всегда f(x₁) < f(x₂) (правее — выше), функция на этом промежутке возрастает. ② Если всегда f(x₁) > f(x₂) (правее — ниже), функция убывает.

(2) Как определить по производной · 증가와 감소의 판정

Из учебника

함수 f(x)가 어떤 열린구간에서 미분가능하고, 이 구간의 모든 x에 대하여
① f′(x) > 0이면 함수 f(x)는 이 구간에서 증가한다.
② f′(x) < 0이면 함수 f(x)는 이 구간에서 감소한다.

По-русски: пусть функция дифференцируема на интервале. ① Если на всём интервале f′(x) > 0, то f там возрастает. ② Если f′(x) < 0, то убывает.

Почему это верно? Здесь снова работает 평균값 정리: для x₁ < x₂ есть c между ними, и f(x₂) − f(x₁) = f′(c)(x₂ − x₁). Если f′(c) > 0, правая часть положительна, значит f(x₂) > f(x₁).

Осторожно · 주의

일반적으로 (2)에서 ①, ②의 역은 성립하지 않는다.

Обратное, вообще говоря, неверно. Функция f(x) = x³ возрастает на всей прямой (−∞, ∞), но f′(x) = 3x² и f′(0) = 0, а не > 0.

В точке 0 тропа на мгновение становится ровной, но потом опять идёт вверх. Мы ни разу не спустились.

Важно для задач · 참고

함수 f(x)가 어떤 열린구간에서 미분가능할 때
① 함수 f(x)가 이 구간에서 증가할 조건 ⇒ f′(x) ≥ 0   ② 감소할 조건 ⇒ f′(x) ≤ 0
일반적으로 ①, ②의 역도 성립하지 않지만, f(x)가 상수함수가 아닌 다항함수이면 ①, ②의 역이 성립한다.

По-русски: если f возрастает, то f′(x) ≥ 0 (с равенством!). Для многочленов (кроме постоянной функции) верно и обратное.

Главный вывод для задач: если в задаче написано «증가하도록 하는» (чтобы функция возрастала) и f — многочлен, пиши условие f′(x) ≥ 0, а не > 0. Для убывания: f′(x) ≤ 0. Знак равенства нельзя терять, иначе потеряешь концы ответа.

3 · 함수의 극대와 극소

Максимум и минимум: вершины холмов и дно ям

Пример из жизни

Представь горный хребет. Каждая вершина — это 극대: в своём районе она выше всех соседних точек. Каждая впадина между горами — 극소: в своём районе она ниже всех.

Слово «локальный» (극) здесь главное. Маленький холм у подножия — тоже вершина, хотя он ниже, чем впадина высоко в горах. Поэтому 극댓값 может быть меньше, чем 극솟값. Посмотри на рисунок ниже.

(1) Определение · 극대와 극소의 정의

Из учебника

함수 f(x)에서 x = a를 포함하는 어떤 열린구간에 속하는 모든 x에 대하여
① f(x) ≤ f(a)일 때, 함수 f(x)는 x = a에서 극대라 하고, f(a)를 극댓값이라 한다.
② f(x) ≥ f(a)일 때, 함수 f(x)는 x = a에서 극소라 하고, f(a)를 극솟값이라 한다.

По-русски: найдётся маленький интервал вокруг a, на котором ① все значения f(x) ≤ f(a): тогда в x = a функция имеет максимум (극대), а число f(a) — значение максимума (극댓값). ② Все f(x) ≥ f(a): минимум (극소), f(a) — значение минимума (극솟값).

(2) Экстремум и производная · 극값과 미분계수

Из учебника

미분가능한 함수 f(x)가 x = a에서 극값을 가지면 f′(a) = 0이다.

По-русски: если дифференцируемая функция имеет экстремум в точке x = a, то f′(a) = 0. На вершине холма и на дне ямы касательная горизонтальна (как в теореме Ролля).

Осторожно · 주의

일반적으로 위의 역은 성립하지 않는다.

Обратное неверно: из f′(a) = 0 не следует, что в a экстремум. Снова f(x) = x³: f′(0) = 0, но в точке 0 нет ни вершины, ни ямы (рисунок выше). Поэтому нужно ещё правило (3).

(3) Как определить экстремум · 극대와 극소의 판정

Из учебника

미분가능한 함수 f(x)에 대하여 f′(a) = 0일 때, x = a의 좌우에서 f′(x)의 부호가
① 양(+)에서 음(−)으로 바뀌면 f(x)는 x = a에서 극대이고, 극댓값은 f(a)이다.
② 음(−)에서 양(+)으로 바뀌면 f(x)는 x = a에서 극소이고, 극솟값은 f(a)이다.

По-русски: пусть f′(a) = 0. Смотрим на знак f′(x) слева и справа от a. ① Знак меняется с + на − (шли вверх, потом вниз): в a максимум. ② С − на + (шли вниз, потом вверх): минимум. Если знак не меняется, экстремума нет.

Разберём пример · 증감표 (таблица)

Найдём промежутки возрастания и убывания и экстремумы функции f(x) = x³ − 3x + 1. (Это наш пример для тренировки, его нет в учебнике. Эту же функцию ты увидишь в лаборатории ниже.)

Шаг 1. Производная: f′(x) = 3x² − 3 = 3(x + 1)(x − 1) Шаг 2. Нули производной: f′(x) = 0 → x = −1 или x = 1 Шаг 3. Знак f′ на каждом куске: парабола ветвями вверх: снаружи корней +, между корнями − Шаг 4. Значения в точках: f(−1) = −1 + 3 + 1 = 3,  f(1) = 1 − 3 + 1 = −1
x…−1…1…
f′(x)+0−0+
f(x)↗3 극대↘−1 극소↗

Ответ: возрастает на (−∞, −1] и [1, ∞), убывает на [−1, 1]. 극댓값 = 3 (при x = −1), 극솟값 = −1 (при x = 1).

5 · 풀이 순서

Как решать задачи: два рецепта

ТИП A · 증가·감소 조건 «Чтобы функция возрастала/убывала…»
  1. Найди f′(x).
  2. Запиши условие: f′(x) ≥ 0 (증가) или f′(x) ≤ 0 (감소). Со знаком равенства!
  3. На всей прямой (실수 전체) и f′ — квадратный трёхчлен: используй D ≤ 0.
  4. На промежутке (p, q) и парабола f′ ветвями вверх: для f′ ≤ 0 достаточно проверить концы: f′(p) ≤ 0 и f′(q) ≤ 0.
ТИП B · 극값 «Найдите 극댓값 / 극솟값»
  1. Найди f′(x) и разложи на множители.
  2. Реши f′(x) = 0.
  3. Составь 증감표: знак f′ слева и справа от каждого корня.
  4. + → − это 극대, − → + это 극소.
  5. Подставь x в саму функцию f, а не в f′.
Где ошибаются чаще всего
  • Пишут D < 0 вместо D ≤ 0 и теряют концы ответа (задача 297: ответ −3 ≤ a ≤ 3, а не −3 < a < 3).
  • Подставляют x в f′, а не в f, когда ищут 극댓값. В f′ всегда получится 0!
  • В задаче «если в x = a 극대/극소» забывают первое уравнение: f′(a) = 0.

296중하 · средняя

함수 f(x) = −x⁴ + 8x³ + 5가 감소하는 구간에 속하는 정수 x의 최솟값을 구하시오.

Перевод: найдите наименьшее целое x, принадлежащее промежутку убывания функции f(x) = −x⁴ + 8x³ + 5.

Подсказка

Вынеси общий множитель: f′(x) = −4x²(…). Множитель x² всегда ≥ 0, поэтому знак определяет только второй множитель.

Решение
f′(x) = −4x³ + 24x² = −4x²(x − 6) −4x² ≤ 0 всегда, поэтому f′(x) ≤ 0 ⇔ x − 6 ≥ 0 ⇔ x ≥ 6 В x = 0 тоже f′ = 0, но слева и справа от 0 знак +: там функция возрастает, это не промежуток убывания. Промежуток убывания: [6, ∞) → наименьшее целое 6

Ответ: 6

297하 · лёгкая

함수 f(x) = −x³ + ax² − 3x + 4가 실수 전체의 집합에서 감소하기 위한 실수 a의 값의 범위는?

Перевод: при каких действительных a функция f(x) = −x³ + ax² − 3x + 4 убывает на всей числовой прямой?

① a ≤ −3② −3 ≤ a < 0③ −3 ≤ a ≤ 3④ 0 ≤ a < 3⑤ a ≥ 3
Подсказка

Тип A: нужно f′(x) ≤ 0 для всех x. f′ — парабола ветвями вниз. Когда она нигде не поднимается выше оси?

Решение

298중하 · средняя

함수 f(x) = x³ + kx² − 15x + 4가 구간 (−3, 1)에서 감소할 때, 실수 k의 값의 범위는 α ≤ k ≤ β이다. 이때 α + β의 값은?

Перевод: функция f(x) = x³ + kx² − 15x + 4 убывает на интервале (−3, 1). Множество значений k: α ≤ k ≤ β. Найдите α + β.

① 2② 4③ 6④ 8⑤ 10
Подсказка

f′(x) = 3x² + 2kx − 15 — парабола ветвями вверх. Чтобы на всём (−3, 1) она была ≤ 0, достаточно, чтобы она была ≤ 0 в обоих концах.

Решение
f′(−3) = 27 − 6k − 15 = 12 − 6k ≤ 0 → k ≥ 2 f′(1) = 3 + 2k − 15 = 2k − 12 ≤ 0 → k ≤ 6 2 ≤ k ≤ 6 → α + β = 8

Почему хватает концов: парабола ветвями вверх «провисает» вниз, поэтому между двумя точками ниже оси она тоже ниже оси.

Ответ: ④ 8

299중하 · средняя

다항함수 y = f(x)의 도함수 y = f′(x)의 그래프가 아래 그림과 같을 때, 다음 중 옳은 것은?

Перевод: на рисунке график производной y = f′(x) многочлена f(x). Какое утверждение верно?

① f(x)는 구간 (−∞, 1)에서 감소한다. ② f(x)는 구간 (1, 2)에서 증가한다. ③ f(x)는 구간 (2, 4)에서 증가한다. ④ f(x)는 구간 (4, 6)에서 감소한다. ⑤ f(x)는 구간 (7, ∞)에서 감소한다.
Подсказка

Ловушка: это график f′, а не f. Не смотри, идёт ли кривая вверх. Смотри, выше или ниже оси x она лежит. Над осью: f возрастает.

Решение
  • f′ > 0 на (−∞, 1), (2, 6), (7, ∞): f возрастает.
  • f′ < 0 на (1, 2), (6, 7): f убывает.
  • ④ ловушка: на (4, 6) график f′ идёт вниз, но лежит над осью, значит f возрастает.

Ответ: ③

함수 f(x) = x³ + ax + 9는 x = −1에서 극대이다. 함수 f(x)의 극솟값은? (단, a는 상수이다.)

Перевод: функция f(x) = x³ + ax + 9 имеет максимум при x = −1. Найдите значение минимума (극솟값). (a — константа.)

① 6② 7③ 8④ 9⑤ 10
Разбор
Шаг 1. «극대 при x = −1» ⇒ f′(−1) = 0 Шаг 2. f′(x) = 3x² + a → 3 + a = 0 → a = −3 Шаг 3. f′(x) = 3x² − 3 = 3(x + 1)(x − 1) Шаг 4. знак: + | −1 | − | 1 | + → x = 1 극소 Шаг 5. 극솟값 = f(1) = 1 − 3 + 9 = 7

Это та же форма, что в нашем примере и в лаборатории (x³ − 3x + …), только график поднят на 9.

Ответ: ② 7

Частые ошибки
  • Смотрят, идёт ли вверх график f′, а надо смотреть, выше или ниже оси он лежит (задача 299).
  • Теряют знак равенства: D < 0 вместо D ≤ 0.
  • Считают, что f′(a) = 0 всегда даёт экстремум.
  • Подставляют корни в f′ вместо f.
  • Думают, что 극댓값 всегда больше 극솟값.
